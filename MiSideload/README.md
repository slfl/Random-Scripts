# MiSideload

Официальная OTA-прошивка Xiaomi через режим **MiAssistant** — напрямую по USB,
без `adb.exe`, без разблокировки загрузчика. Только официальные подписанные
прошивки и штатная серверная валидация Xiaomi.

© 2026 (Mansi) · Github — https://github.com/slfl/Random-Scripts/tree/main/MiSideload

---

## Что это и зачем

Стоковый `adb sideload` на телефонах Xiaomi не работает: рекавери в режиме
MiAssistant требует в команде `sideload-host` серверный токен `Validate`,
который выдаёт сервер Xiaomi под конкретный пакет и устройство. MiSideload
делает всю цепочку сам: снимает данные с телефона, считает MD5 прошивки,
получает токен и заливает пакет.

Инструмент нативный (Win32, один `.exe`, только системные библиотеки Windows),
поэтому ничего доустанавливать не нужно.

Типичное применение — восстановление работоспособности телефона после сбоя
обновления **с сохранением данных** (флаг wipe по умолчанию выключен).

## Как это работает

1. **USB / ADB.** Телефон в MiAssistant отдаёт ADB-интерфейс (класс `ff/42/01`).
   Утилита открывает его через WinUSB и говорит на ADB-протоколе напрямую
   (CNXN/OPEN/OKAY/WRTE/CLSE).
2. **Информация об устройстве.** Через сервисы рекавери снимаются
   `getdevice/getversion/getsn/getcodebase/getbranch/getregion/getromzone`.
3. **Ключ (токен).** Собирается JSON-запрос, шифруется **AES-128-CBC**
   (ключ/IV фиксированы протоколом), Base64 → POST на
   `https://update.miui.com/updates/miotaV3.php`. Ответ расшифровывается тем же
   ключом; из `PkgRom.Validate` берётся токен, из `PkgRom.Erase` — требование
   очистки данных (кросс-регион).
4. **Заливка.** `sideload-host:<size>:<block>:<validate>:<wipe>` — далее штатный
   блочный обмен: телефон запрашивает блоки по номеру, утилита их отдаёт.
   Завершение — `DONEDONE` (успех) или `FAILFAIL` (отказ). После полной передачи
   телефон сам проверяет и устанавливает образ.

Подпись прошивки при этом по-прежнему проверяет сам рекавери — ничего не
обходится, токен лишь авторизует конкретный официальный пакет.

## Возможности

- Нативный Win32 GUI под стиль Win10/11, x64 и x86, DPI-масштабирование, ресайз.
- Меню:
  - **Меню** — открыть файл, информация о телефоне, проверить сервер, страница
    загрузок, запустить прошивку, о программе, выход.
  - **ADB** — указать путь до `adb.exe`, сбросить путь, проверить adb (`version`),
    kill-server (+ `taskkill` для посторонних adb).
  - **Настройки** — очистка данных после прошивки (wipe, по умолчанию выкл),
    сохранение логов, щадящий режим передачи (16 КБ + микропауза), язык RU/EN.
- Подробный лог всего процесса (запрос токена, ответ сервера, ход передачи по
  блокам и процентам), прогресс-бар, мониторинг подключения устройства.
- Сохранение логов сессии в папку `Logs` рядом с программой
  (`MiSideload-ДД.ММ.ГГ-ЧЧ.ММ.log`, UTF-8).
- Авто-повтор сессии при обрыве связи (до 3 попыток).
- Полная локализация интерфейса и логов (русский / английский).

## Как пользоваться

1. Ввести телефон в рекавери и выбрать **«Connect with MiAssistant / 连接小米助手»**,
   подключить по USB.
2. **ADB → Kill server** (освобождает интерфейс, если его держит adb-сервер).
3. **Меню → Информация о телефоне** — убедиться, что устройство определяется.
4. **Меню → Открыть файл** — выбрать официальный OTA `.zip`.
5. При необходимости — **Настройки → Очищать данные после прошивки** (wipe).
6. **Меню → Запустить прошивку**. Дождаться 100% передачи, дальше телефон
   устанавливает образ сам (не отключать; первая загрузка — до ~10–15 минут).

## Требования

- Windows 8.1/10/11 (x64 или x86).
- Драйвер **WinUSB** на ADB-интерфейсе телефона. Обычно ставится сам
  (Google/Xiaomi WinUSB). Если утилита пишет `WinUsb_Initialize failed` —
  поставить WinUSB через Zadig на интерфейс с VID `18D1`/`2717` и классом
  `ff/42/01`.
- Ничего больше: только системные DLL Windows.

## Сборка

MinGW-w64:

```
windres app.rc -O coff -o app_res.o
x86_64-w64-mingw32-gcc -O2 -mwindows -o MiSideload.exe mi_sideload_gui.c app_res.o \
  -lsetupapi -lwinusb -lwinhttp -lbcrypt -lcrypt32 -lcomctl32 -lcomdlg32 \
  -lgdi32 -luser32 -ladvapi32 -lshell32 -static -static-libgcc
```

Строка для MSVC — в шапке `mi_sideload_gui.c`.

## Файлы

- `mi_sideload_gui.c` — весь исходник (USB/ADB, крипта, HTTP, GUI).
- `app.manifest`, `app.rc`, `app.ico` — манифест (visual styles + DPI), ресурсы, иконка.
- `MiSideload.exe` / `MiSideload_x86.exe` — готовые сборки (x64 / x86).
- `xiaomi_sideload.py` — ранняя кроссплатформенная CLI-версия на Python (libusb),
  для Linux/WSL.

## Дисклеймер

Прошивка устройства выполняется на свой риск. Используются только официальные
подписанные прошивки и штатная валидация Xiaomi; загрузчик не разблокируется и
подпись не обходится. Автор не несёт ответственности за возможные последствия.
