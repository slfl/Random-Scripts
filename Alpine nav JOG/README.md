# JOG Emulator — эмулятор пульта навигации Honda Civic 5D (Alpine)

Эмуляция штатного джойстика (JOG) головного устройства навигации Honda Civic 5D
(Alpine, WinCE 4.2). Позволяет управлять блоком на стенде без штатного пульта:
Arduino генерирует кадры протокола, HTML‑страница в браузере — удобный пульт.

## Состав проекта

| Файл | Назначение |
|------|-----------|
| `jog_emulator.ino` | Скетч Arduino: принимает текстовые команды по USB (9600) и шлёт кадры JOG (4800, инверсия) |
| `jog_control.html` | Пульт в браузере (Chrome/Edge, Web Serial API). Открывается локально, ничего устанавливать не нужно |

## Протокол JOG (результат реверс‑инжиниринга)

- Физика: один сигнальный провод, уровень 0–5 В, **покой = LOW**.
- Кодирование: **UART 4800 бод, 8N1, LSB‑first, ИНВЕРТИРОВАННЫЙ**.
- Кадр — 4 байта: `[тип][маска_млад][маска_старш][cks]`.
- Контрольная сумма: **сумма всех 4 байт = 0xFF**, т.е. `cks = 0xFF − тип − млад − старш`.
- Кнопки (тип `0x80`): кадр повторяется ~каждые **90 мс**, пока кнопка зажата.
  Отпускание — кадр `80 00 00 7F`.
- Маска битовая: можно зажимать **несколько кнопок одновременно** (биты складываются по OR).
- Энкодер: **один кадр на щелчок**, без отпускания.
  - По часовой (CW): `81 00 00 7E`
  - Против часовой (CCW): `FF 00 00 00`

### Карта кнопок

| Кнопка | Кадр | Бит |
|--------|------------------|-------------|
| MAP | `80 01 00 7E` | млад `0x01` |
| BRIGHTNESS (яркость) | `80 02 00 7D` | млад `0x02` |
| CLIMATE | `80 04 00 7B` | млад `0x04` |
| INFO | `80 10 00 6F` | млад `0x10` |
| MENU | `80 20 00 5F` | млад `0x20` |
| ENTER (PUSH ENT) | `80 40 00 3F` | млад `0x40` |
| LEFT ◀ | `80 00 01 7E` | старш `0x01` |
| DOWN ▼ | `80 00 02 7D` | старш `0x02` |
| RIGHT ▶ | `80 00 04 7B` | старш `0x04` |
| UP ▲ | `80 00 08 77` | старш `0x08` |
| BACK ↩ | `80 00 20 5F` | старш `0x20` |
| AUDIO | `80 00 40 3F` | старш `0x40` |
| Энкодер CW | `81 00 00 7E` | тип `0x81` |
| Энкодер CCW | `FF 00 00 00` | тип `0xFF` |
| Комбинация MAP+MENU | `80 21 00 5E` | млад `0x21` (OR битов) |

### Сигнал работы интерфейс‑набора (heartbeat)

Из документации: линия «0–5 В пульсирует»; если линия оборвана **или** замкнута на массу —
навигация не стартует. Т.е. блоку нужен «живой» контроллер. Режим `beat` эмулятора
постоянно шлёт кадр отпускания (`80 00 00 7F`) каждые ~90 мс — это создаёт пульсацию
на линии. Если блок не стартует от этого, нужно отдельно замерить частоту на
heartbeat‑линии рабочего блока и воспроизвести её.

## Подключение

```
Arduino (5В: Uno/Nano/Mega)        Головное устройство
  D8  ─────────────────────────────  линия JOG
  GND ─────────────────────────────  GND (масса)
```

- Плата обязательно **5‑вольтовая** — уровень сигнала должен быть 0–5 В.
- **Общая земля обязательна.**
- Не подавать на линию больше 5 В.

## Прошивка и запуск

1. Открыть `jog_emulator.ino` в Arduino IDE, выбрать плату/порт, прошить.
2. Закрыть Serial Monitor (порт может держать только одна программа).
3. Открыть `jog_control.html` в **Chrome** или **Edge** (Web Serial; Firefox/Safari не подходят).
4. Нажать «Подключить Arduino», выбрать COM‑порт платы.
5. Нажимать кнопки. Удержание честное: кадры идут, пока кнопка зажата мышью/пальцем.

Если страница открыта с `file://` и порт не запрашивается, можно поднять локальный
сервер: `python -m http.server` в папке с файлом → `http://localhost:8000/jog_control.html`.

## Команды скетча (Serial, 9600)

Их шлёт HTML‑пульт, но можно и вручную из любого терминала:

| Команда | Действие |
|---------|----------|
| `hold LO HI` | Нажать и держать маску (hex). Пример: `hold 21 00` = MAP+MENU |
| `rel` | Отпустить (кадр `80 00 00 7F`) |
| `cw [N]` | Энкодер по часовой, N щелчков (по умолчанию 1) |
| `ccw [N]` | Энкодер против часовой |
| `beat` | Вкл/выкл heartbeat (постоянная отправка отпускания ~90 мс) |
| `map`, `menu`, `back`, `audio`, `info`, `climate`, `brightness`, `enter`, `up`, `down`, `left`, `right` | Одиночное нажатие (3 кадра + отпускание) |

## Пульт в браузере

- Раскладка повторяет штатный блок: слева MAP / CLIMATE / BACK, в центре джойстик
  (▲▼◀▶, PUSH ENT, кольца ↺CCW / ↻CW), справа MENU / AUDIO / INFO, правее — яркость ☀
  и кнопка **«Инженерное меню»** (держит MAP+MENU, пока нажата).
- Любую кнопку можно удерживать — отправка идёт до отпускания.
- Чекбокс **heartbeat** — для попытки запуска блока на стенде.
- Внизу — лог команд и ответов Arduino.

## Как был вскрыт протокол (кратко)

1. Logic‑анализатор (Saleae) на линии JOG: покой LOW, пачки импульсов при нажатиях.
2. Ширины импульсов оказались кратны ~206 мкс → бит 4800 бод.
3. Декодер Async Serial: 4800, 8N1, **Inverted** → стабильные 4‑байтовые кадры.
4. Сопоставление кадров с нажатиями → карта кнопок; проверка контрольной суммы
   (сумма = 0xFF) сошлась на всех кадрах, включая аккорды (MAP+MENU = `80 21 00 5E`).

## Замечания

- Скорость USB‑порта (9600) и скорость линии JOG (4800) — разные вещи, не путать.
- При зажатой кнопке блок видит повтор кадров каждые ~90 мс — так делает и штатный пульт.
- Тайминг повтора задан в скетче константой `PERIOD` (90 мс) — можно менять.
