# JOG эмулятор для Honda Civic 5D (Alpine навигация) на RP2040

Эмулятор штатного пульта **JOG** заводской навигации Alpine (WinCE/SH-4) на базе
**Raspberry Pi Pico (RP2040)**. Позволяет управлять навигатором с ПК через
веб-интерфейс (Web Serial) или из последовательного терминала, формируя на линии
данных сигнал, электрически и логически идентичный штатному пульту.

Автор: **SLFL**

## Аппаратная часть

### Разъём JOG навигатора (CN1)

| Пин | Назначение |
|-----|-----------|
| 1 | пусто |
| 2 | +12 В (питание пульта от навигатора) |
| 3 | GND |
| 4 | GND |
| 5 | линия данных |

В покое (без пульта) навигатор держит линию данных на **3.3 В** (внутренняя
подтяжка). Пульт «садит» её в LOW и формирует данные.

### Выходной каскад (повторяет схему штатного пульта)

Штатный пульт управляет линией не напрямую, а через **NPN-транзистор с открытым
коллектором** (в оригинале — SOT23, база подперта через резистор **10 кОм**).
Прямое подключение GPIO к линии даёт «жёсткий» ноль и глушит шину; транзистор даёт
«мягкий» ноль (Vce_sat), как у оригинала.

```
RP2040 GPIO2 ──[10 кОм]── база  (BC847C, NPN)
                коллектор ────── линия данных (pin 5 разъёма)
                эмиттер  ─────── GND (общий с навигатором)
```

- Подтяжку линии к 3.3 В обеспечивает сам навигатор.
- **Транзистор инвертирует сигнал:** GPIO `HIGH` → транзистор открыт → линия `LOW`;
  GPIO `LOW` → транзистор закрыт → линия `HIGH`.
- **12 В к Pico не подключать.** Земля Pico — общая с навигатором.

## Протокол (подтверждён захватом: логический анализатор + осциллограф)

- **Скорость:** 4800 бод (≈208 мкс/бит), формат **8N1**, **LSB-first**.
- **Линия:** покой `LOW`, сигнал инвертированный (инверсию делает транзистор; на
  базу RP2040 подаёт обычный, неинвертированный UART).
- **Кадр — 4 байта:** `[type] [lo] [hi] [cks]`, где
  `(type + lo + hi + cks) & 0xFF == 0xFF` (т.е. `cks = 0xFF − (type+lo+hi)`).
- `type`: `0x80` — кнопки (маски `lo`/`hi`), `0x81` — энкодер CW, `0xFF` — энкодер CCW.

### Маски кнопок

`lo`-байт: `MAP=0x01  BRIGHT=0x02  CLIMATE=0x04  INFO=0x10  MENU=0x20  ENTER=0x40`
`hi`-байт: `LEFT=0x01  DOWN=0x02  RIGHT=0x04  UP=0x08  BACK=0x20  AUDIO=0x40`
Диагонали джойстика — побитовое ИЛИ направлений в `hi`.

### Полная таблица кадров

| Кнопка | Кадр | | Кнопка | Кадр |
|--------|------|-|--------|------|
| MAP | `80 01 00 7E` | | UP | `80 00 08 77` |
| BRIGHT | `80 02 00 7D` | | DOWN | `80 00 02 7D` |
| CLIMATE | `80 04 00 7B` | | LEFT | `80 00 01 7E` |
| INFO | `80 10 00 6F` | | RIGHT | `80 00 04 7B` |
| MENU | `80 20 00 5F` | | UP+LEFT | `80 00 09 76` |
| ENTER | `80 40 00 3F` | | UP+RIGHT | `80 00 0C 73` |
| BACK | `80 00 20 5F` | | DOWN+LEFT | `80 00 03 7C` |
| AUDIO | `80 00 40 3F` | | DOWN+RIGHT | `80 00 06 79` |
| ENC CW | `81 00 00 7E` | | ENC CCW | `FF 00 00 00` |
| RELEASE | `80 00 00 7F` | | ENG (MAP+MENU+BACK) | `80 21 20 3E` |

### Отпускание (RELEASE)

Кадр `80 00 00 7F` («все клавиши отпущены») штатный пульт шлёт **только после
направлений джойстика** — UP / DOWN / LEFT / RIGHT и диагоналей. Остальные кнопки
(MAP, CLIMATE, MENU, ENTER, BACK, AUDIO, INFO, BRIGHT) и энкодер отпускание **не
шлют**. В прошивке это учтено: `BTN <направление>` сам отправляет RELEASE.

## Прошивка RP2040

Среда: **Arduino IDE** + ядро **arduino-pico** (Earle Philhower). Плата —
Raspberry Pi Pico. USB-Serial на 115200.

Значения по умолчанию уже выставлены под транзисторный каскад:
`bit=208  gap=900  inv=0  msb=0  drive=pp  rel=60`.

### Команды (терминал, 115200, конец строки CR или LF)

| Команда | Действие |
|---------|----------|
| `BTN <name>` | нажать кнопку. Направления (`UP DOWN LEFT RIGHT UL UR DL DR`) сами шлют RELEASE |
| | прочие: `MAP CLIMATE MENU ENTER BACK AUDIO INFO BRIGHT ENG` |
| `CW` / `CCW` | энкодер по / против часовой |
| `KEY <lo> <hi>` | кнопка по маскам (hex), напр. `KEY 00 09` = UP+LEFT |
| `REL` | отпускание (`80 00 00 7F`) |
| `RAW <hex>` | сырые байты |
| `CFG?` | показать настройки |
| `CFG inv=0 drive=pp bit=208 gap=900 rel=60` | изменить параметры линии |
| `BTN?` | список кнопок |
| `HELP` | справка |

## Веб-пульт (`jog_control.html`)

1. Открыть файл в **Chrome** или **Edge** (Web Serial; Firefox/Safari не подходят).
2. Закрыть Serial Monitor в Arduino IDE (порт должен быть свободен).
3. «Подключить» → выбрать COM-порт Pico (115200).
4. Управление: кнопки слева/справа, джойстик с диагоналями, энкодер, «Инженерное
   меню». Кнопку можно удерживать (кадр повторяется); направления при отпускании
   шлют RELEASE, остальные — нет.

Карточка «Параметры линии» позволяет на лету менять `bit/gap/inv/drive/rel` и
применять их в прошивку.

---

## Быстрый старт

1. Собрать каскад: `GPIO2 → 10 кОм → база BC847C`, `коллектор → pin5`,
   `эмиттер → GND` (общая земля с навигатором).
2. Прошить `jog_emulator_rp2040.ino`.
3. Открыть `jog_control.html` (или терминал) и подключиться к Pico.
4. Нажать `ENTER` / стрелку.

## Статус проекта (честно)

Эмулятор формирует сигнал, который по всем измеримым параметрам **неотличим от
штатного пульта**: байты, скорость 4800 бод, полярность, контрольная сумма, уровни
напряжения (3.3 В), «мягкий» транзисторный ноль через **тот же выходной каскад с
тем же резистором 10 кОм**. Идентичность подтверждена логическим анализатором и
осциллографом.

**Однако на момент текущей версии навигатор на эмулятор не отвечает**, при том что:
- на штатный пульт реагирует нормально;
- два штатных пульта работают на одной линии параллельно.

В ходе отладки исключены: формат данных, скорость, полярность, уровни напряжения,
определение присутствия по 12 В, инициализация при включении, уровень покоя, тип и
сила драйва. По микроконтроллеру пульта (Toshiba **TMP87C447**, TLCS-870) даташит
показал простой сканер кнопок без скрытого протокола.
