# GoodFon Wallpaper Changer

Автоматическая смена обоев рабочего стола Windows картинками с сайта
[goodfon.com](https://www.goodfon.com). Скрипт умеет скачивать случайные обои
нужного разрешения по выбранной теме, вести собственную папку избранного
(синхронизированную с избранным на сайте), показывать уведомления в трее и
корректно вести себя при любых сбоях сайта — переключаясь на локальные картинки.

Проект существует в двух исполнениях с **идентичной логикой**:

* **Python** (`GoodFon.py`) — оригинальная реализация. Требует установленного
  Python и нескольких библиотек.
* **Go** (`GoodFon.exe` + `main.go`) — скомпилированная версия. Один
  самодостаточный `.exe` без зависимостей и без установленного Python.

## Какую версию выбрать

| | Python | Go (.exe) |
|---|---|---|
| Установка Python | Нужна | Не нужна |

логику без пересборки.

## Быстрый старт

### Go-версия (рекомендуется)

1. Положить `GoodFon.exe` и `config.ini` в одну папку.
2. Заполнить `config.ini` (см. ниже).
3. Запустить `GoodFon.exe` — обои сменятся.

### Python-версия

1. Установить зависимости:
   ```
   py -m pip install requests beautifulsoup4 pywin32 winotify
   ```
2. Положить `GoodFon.py` и `config.ini` в одну папку.
3. Запустить:
   ```
   py GoodFon.py
   ```

> При установке через `pywin32` модуль `pythoncom` ставится автоматически —
> отдельно `pip install pythoncom` делать **не нужно** (такого пакета нет).
> Если после установки `pywin32` модуль не находится, выполните один раз:
> ```
> py <путь к Python>\Scripts\pywin32_postinstall.py -install
> ```

## Конфигурация (config.ini)

Единый файл настроек для обеих версий. Должен лежать **рядом** с `.exe`
(или с `.py`).

```ini
[auth]
login = your_login
password = your_password

[settings]
resolution = 1920x1080
theme = nature
save_dir = C:\Users\USER\Pictures\GoodFon
max_files = 10
like_every_n = 10
max_attempts = 3
notify = true

[state]
counter = 0
```

### Параметры

| Секция | Ключ | Описание |
|---|---|---|
| `auth` | `login` | Логин аккаунта на goodfon.com |
| `auth` | `password` | Пароль аккаунта |
| `settings` | `resolution` | Разрешение скачиваемых обоев, напр. `1920x1080`, `2560x1440`. Если у конкретной картинки такого размера нет — она пропускается |
| `settings` | `theme` | Тема (раздел сайта) — часть URL. Для `goodfon.com/nature/` тема = `nature` |
| `settings` | `save_dir` | Папка для скачанных обоев. Создаётся автоматически |
| `settings` | `max_files` | Сколько последних файлов хранить в основной папке. Старые удаляются |
| `settings` | `like_every_n` | Каждый N-й запуск обои берутся из избранного, а не с сайта |
| `settings` | `max_attempts` | Число попыток при сбоях сайта за один запуск |
| `settings` | `notify` | Уведомления в трее: `true` / `false` |
| `state` | `counter` | Счётчик запусков. **Управляется скриптом, вручную не трогать** |

### Как узнать имя темы

Откройте нужный раздел на сайте, например `https://www.goodfon.com/cars/` —
имя темы это `cars`. Его и впишите в `theme`.

## Структура папок при работе

```
📁 save_dir                       (напр. C:\Users\USER\Pictures\GoodFon\)
├── 📁 Like\
│   ├── 📁 nature\                 ← избранное для темы nature
│   │   ├── wallpaper-a.jpg
│   │   └── wallpaper-b.jpg
│   └── 📁 cars\                   ← избранное для темы cars
│       └── ...
├── последние_обои_1.jpg           ← кэш скачанных с сайта (max_files штук)
├── последние_обои_2.jpg
└── ...
```

* Избранное хранится в подпапке по теме: `Like\<тема>\`. При смене темы в
  конфиге избранное других тем не затрагивается, и ссылки на сайт остаются
  корректными.
* Имена файлов сохраняются «как на сайте» — это позволяет восстановить URL
  страницы картинки для операций с избранным.

## Команды и аргументы

```
GoodFon.exe                # update — сменить обои (по умолчанию)
GoodFon.exe update         # то же самое явно
GoodFon.exe like           # добавить текущие обои в избранное
GoodFon.exe unlike         # убрать текущие обои из избранного
```

Только для **Go-версии** дополнительно есть флаг логирования в файл:

```
GoodFon.exe -logfile           # writeлог в goodfon.log рядом с .exe
GoodFon.exe update -logfile    # порядок и регистр не важны
GoodFon.exe -logfile like
```

### update
Обновляет обои. По счётчику решает — взять картинку с сайта или из избранного.

### like
* Копирует текущие обои в `Like\<тема>\`.
* Добавляет картинку в избранное на сайте.
* **Переключает обои на копию из `Like`** — это нужно, чтобы последующий
  `unlike` корректно определил картинку.

### unlike
* Определяет текущие обои через реестр Windows.
* Удаляет картинку из избранного на сайте.
* Удаляет локальную копию из `Like\<тема>\`.
* Сразу загружает новые обои с сайта.
* Срабатывает только если текущие обои находятся в `Like\<тема>\`
  (иначе нечего «разлюбливать»).

## Как это работает изнутри

### Обычная смена обоев (`update`)

1. **Проверка доступности сайта.** Лёгкий запрос с коротким таймаутом (8 с).
   Если сайт не отвечает — счётчик увеличивается и ставится картинка из
   избранного, без попытки логина.
2. **Авторизация.** GET страницы логина → извлечение CSRF-токена →
   POST логина/пароля. Сессия с cookie хранится на время запуска.
3. **Счётчик.** Читается из `config.ini`, увеличивается на 1, записывается
   обратно. Если достиг `like_every_n` — сбрасывается в 0, и обои берутся из
   избранного (`Like\<тема>\`), запуск завершается.
4. **Пагинация.** Загружается первая страница раздела, по ссылкам вида
   `index-N.html` определяется максимальный номер страницы.
5. **Случайная страница и картинка.** Берётся случайная страница раздела,
   с неё собираются ссылки на страницы картинок, выбирается случайная.
6. **Поиск нужного разрешения.** На странице картинки ищется ссылка строго
   с `wallpaper-download-<разрешение>-`. Если такой нет — картинка пропускается,
   берётся следующая.
7. **Страница загрузки.** Переход на найденную ссылку. Проверяется маркер
   превышения суточного лимита. Если лимит исчерпан — переключение на избранное.
8. **Ссылка на файл.** Со страницы загрузки берётся прямой адрес оригинала
   из `<a class="js-download_img" href="...">`.
9. **Скачивание.** Файл скачивается. Если сервер `img.goodfon.com` недоступен —
   автоматически пробуется `img.goodfon.ru` (и наоборот).
10. **Сохранение и установка.** Файл сохраняется в `save_dir`, старые файлы
    сверх `max_files` удаляются, обои устанавливаются, показывается уведомление.

Шаги 4–10 выполняются в цикле до `max_attempts` попыток — при любой ошибке
(таймаут, 502, пустая страница, отсутствие разрешения) берётся следующая
попытка. Ошибка пагинации тоже не фатальна — следующая попытка повторит её.
Если все попытки исчерпаны — ставится локальная картинка.

### Логика избранного

URL страницы картинки восстанавливается из имени файла:
`Like\nature\holly-peers-7513.jpg` → `goodfon.com/nature/wallpaper-holly-peers-7513.html`.
На этой странице в блоке избранного (`a.js-favorite`) есть атрибуты
`data-add="/api/fon/favorite/add/<id>/"` и `data-del=".../del/<id>/"` —
GET по нужному адресу добавляет/удаляет картинку из избранного.

«Текущая» картинка определяется по пути в реестре
`HKCU\Control Panel\Desktop\Wallpaper` — это гарантирует, что `unlike`
работает именно с тем, что сейчас на экране.

## Уведомления

| Ситуация | Заголовок | Тело |
|---|---|---|
| Обои с сайта | `Обои обновлены — с сайта` | имя файла |
| Обои из избранного | `Обои обновлены — из избранного` | имя файла |
| Обои локально (сбой сайта) | `Обои обновлены — локально` | имя файла |
| Добавлено в избранное | `Добавлено в избранное` | имя файла |
| Удалено из избранного | `Удалено из избранного` | имя файла |
| Лимит исчерпан | `GoodFon: лимит исчерпан` | `Загружаем из избранного` |
| Ошибка / нет картинок | `GoodFon: ошибка` | описание |

Отключаются в `config.ini`: `notify = false`.

> **Go-версия** регистрирует свой `AppUserModelID` в реестре
> (`HKCU\Software\Classes\AppUserModelId\GoodFon`) — это убирает ограничение
> Windows на показ тостов от «неизвестного» приложения и заодно показывает
> имя «GoodFon» в шапке уведомления.

## Поведение при сбоях сайта

| Ситуация | Поведение |
|---|---|
| Сайт недоступен при старте | Обои из `Like\<тема>\`, без логина |
| Ошибка логина | Обои из `Like\<тема>\` |
| Ошибка пагинации (502, таймаут) | Повтор попытки до `max_attempts` |
| Таймаут при скачивании | Повтор с другой картинкой |
| Сервер картинок `.com` недоступен | Автопереключение на `.ru` |
| Исчерпан суточный лимит загрузок | Обои из `Like\<тема>\` |
| Нужного разрешения нет у картинки | Пропуск, следующая картинка |
| Все попытки исчерпаны | Обои из локальной папки |

## Автозапуск через Планировщик задач

1. Открыть **Планировщик задач** (`taskschd.msc`).
2. **Создать задачу** (не «простую»).
3. **Общие**: имя задачи; при желании «Выполнять с наивысшими правами».
4. **Триггеры** → создать → «По расписанию» → «Повторять каждые 10 минут» →
   «в течение: Бессрочно».
5. **Действия** → создать → «Запуск программы»:
   * **Go-версия**
     * Программа: `C:\Users\USER\Pictures\GoodFon.exe`
     * (Окно не появляется — GUI-режим. Для логов добавьте аргумент `-logfile`.)
   * **Python-версия**
     * Программа: `C:\Users\USER\AppData\Local\Programs\Python\Python313\pythonw.exe`
     * Аргументы: `"C:\Users\USER\Pictures\GoodFon.py"`
     * (`pythonw.exe`, а не `python.exe` — чтобы не было окна консоли.)
6. Сохранить.

## Контекстное меню рабочего стола

Файл `goodfon.reg` добавляет три пункта в меню по правому клику на рабочем
столе: сменить обои, добавить и убрать из избранного.

**Перед применением** откройте `goodfon.reg` в блокноте и замените путь
`C:\\Users\\USER\\Pictures\\GoodFon.exe` на свой (обратные слэши удваиваются).
Для Python-версии замените строки `command` на вызов
`pythonw.exe "путь\GoodFon.py" update|like|unlike`.

Иконки берутся из системных DLL:
* `imageres.dll,-70` — смена обоев;
* `shell32.dll,43` — добавить в избранное (звёздочка);
* `shell32.dll,131` — убрать из избранного.

> Индексы иконок отличаются между версиями Windows. Если иконка «не та» —
> подберите номер: в PowerShell можно экспортировать все иконки из
> `imageres.dll` / `shell32.dll` в картинки и выбрать нужный индекс.

## Самостоятельная сборка

### Go → .exe

```
go build -ldflags "-s -w -H windowsgui" -o GoodFon.exe .
```

* `-s -w` — убрать отладочную информацию (меньше размер);
* `-H windowsgui` — GUI-режим: окно консоли не создаётся.

Кросс-компиляция из Linux/macOS:
```
GOOS=windows GOARCH=amd64 go build -ldflags "-s -w -H windowsgui" -o GoodFon.exe .
```

### Python → .exe (PyInstaller)

```
py -m pip install pyinstaller
pyinstaller --onefile --noconsole GoodFon.py
```

> В коде уже учтён нюанс PyInstaller: путь к `config.ini` берётся от каталога
> с `.exe` (через `sys.executable`), а не от временной папки распаковки
> `_MEIxxxx`. Поэтому `config.ini` нужно класть рядом с собранным `.exe`.

## Различия Python- и Go-версий

| Аспект | Python | Go |
|---|---|---|
| Установка обоев | `IActiveDesktop` (плавный переход) | `SystemParametersInfo` |
| Уведомления | библиотека `winotify` | встроенный toast через PowerShell + регистрация AppID |
| Парсинг HTML | BeautifulSoup | регулярные выражения (stdlib) |
| Скрытый запуск | `pythonw.exe` | GUI-режим (встроен) |
| Логи | модуль `logging` в консоль | консоль (если запуск из терминала) или `goodfon.log` (флаг `-logfile`) |

> **О формате WebP.** Сайт иногда отдаёт `.webp`. `SystemParametersInfo`
> (Go-версия) устанавливает как обои jpg/png/bmp надёжно; webp может
> потребовать установленного в Windows кодека WebP. Если webp не встаёт —
> можно добавить конвертацию в jpg при сохранении.

### Логи Go-версии подробнее

* Запуск **из терминала** → логи выводятся в этот терминал
  (через `AttachConsole`).
* Запуск **двойным кликом / Планировщиком**:
  * без `-logfile` → логи никуда не пишутся (файл не растёт);
  * с `-logfile` → пишутся в `goodfon.log` рядом с `.exe`. Файл
    самоограничивается: при превышении 1 МБ он обнуляется.

## Описание функций

Имена функций приведены для обеих версий (логика совпадает; в Go — те же по
смыслу, с поправкой на синтаксис).

### Конфигурация и состояние
* `load_config` — читает `config.ini`, заполняет глобальные настройки.
* `read_counter` / `write_counter` — чтение и запись счётчика запусков в
  секции `[state]`.

### Windows
* `set_wallpaper` — устанавливает картинку как обои рабочего стола.
* `get_current_wallpaper_path` — читает путь к текущим обоям из реестра.
* `notify` — показывает уведомление в трее (если включено).

### Сеть и авторизация
* `is_site_available` — быстрая проверка доступности сайта.
* `login_session` — авторизация, возвращает сессию с cookie.
* `get_csrf_token_from_page` — извлекает CSRF-токен со страницы логина.

### Поиск и скачивание
* `get_max_pages` — определяет число страниц в разделе по пагинации.
* `get_random_wallpaper_page_url` — формирует URL случайной страницы раздела.
* `collect_wallpaper_links` — собирает ссылки на страницы картинок.
* `find_download_href_on_image_page` — находит ссылку на оригинал нужного
  разрешения; бросает «лимит исчерпан», если упёрлись в квоту; возвращает
  пусто, если разрешения нет.
* `download_final_image` — скачивает файл с резервом домена `.com`↔`.ru`.
* `save_image_and_get_path` — сохраняет файл в `save_dir`.
* `cleanup_old_images` — удаляет старые файлы сверх `max_files`.

### Избранное
* `get_favorite_ids` — достаёт `data-add` / `data-del` со страницы картинки.
* `get_last_downloaded_file` — последний скачанный файл из основной папки.
* `set_wallpaper_from_like` — случайная картинка из `Like\<тема>\`
  (без повтора текущей).
* `add_to_like` — копирует в `Like\<тема>\`, переставляет обои на копию,
  добавляет на сайт.
* `remove_from_like` — определяет текущие обои, удаляет с сайта и локально.

### Прочее
* `fallback_local` — ставит локальную картинку (из избранного или из основной
  папки), без повтора текущей.
* `main` — точка входа: разбор аргумента, проверка сайта, ветвление
  `update` / `like` / `unlike`, цикл попыток скачивания.

## Решение проблем

**`FileNotFoundError: config.ini не найден` / путь `_MEIxxxx`.**
`config.ini` должен лежать рядом с `.exe` (или `.py`). В собранном через
PyInstaller `.exe` путь уже берётся от каталога с `.exe`.

**`ModuleNotFoundError: No module named 'requests'` (Python).**
После переустановки Python библиотеки нужно поставить заново:
`py -m pip install requests beautifulsoup4 pywin32 winotify`.

**Уведомления не приходят (Go).**
Версия регистрирует `AppUserModelID` автоматически. Если тостов нет —
проверьте, что в Windows включены уведомления и не активен режим «Не беспокоить».

**WebP не ставится как обои.**
Установите расширение «Изображения WebP» из Microsoft Store или используйте
тему, отдающую jpg/png.

**`unlike` пишет «Текущие обои не из папки избранного».**
`unlike` работает только когда на экране картинка из `Like\<тема>\`. После
`like` обои автоматически переключаются на копию из `Like`, так что связка
`like` → `unlike` работает корректно. Если обои сменились на «сайтовые» —
сначала поставьте картинку из избранного.

**Окно консоли мелькает (Go).**
Убедитесь, что `.exe` собран с `-H windowsgui`. Готовый `GoodFon.exe` из
комплекта уже собран в этом режиме.
