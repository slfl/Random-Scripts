# GoodFon Wallpaper Changer

Скрипт на Python для автоматической смены обоев рабочего стола Windows. Загружает случайные обои с сайта [goodfon.com](https://www.goodfon.com) по выбранной теме, поддерживает папку избранных, уведомления в трей и умный fallback при недоступности сайта.

---

## Возможности

- Автоматически меняет обои по расписанию через Планировщик задач Windows
- Загружает случайные обои нужного разрешения по выбранной теме
- Каждый N-й запуск устанавливает картинку из папки избранных (`Like/тема/`)
- При превышении суточного лимита скачиваний автоматически переключается на избранное
- При недоступности сайта меняет обои локально без ошибок
- Добавление и удаление обоев из избранного — локально и на сайте одновременно
- Уведомления в трей Windows с разными иконками для каждой ситуации
- Контекстное меню рабочего стола для быстрого управления
- Все настройки в одном файле `config.ini` — скрипт трогать не нужно

---

## Требования

- Windows 10 / 11
- Python 3.10+
- Аккаунт на [goodfon.com](https://www.goodfon.com) для доступа к новым разделам + 20 картинок в день.

## Установка

### 1. Установить зависимости

```
py -m pip install requests beautifulsoup4 pywin32 winotify
```

### 2. Разместить файлы

Положить `GoodFon.py` и `config.ini` в одну папку, например:

```
C:\Users\USER\Pictures\
├── GoodFon.py
└── config.ini
```

### 3. Настроить config.ini

Открыть `config.ini` и заполнить по своим данным (см. раздел Конфигурация ниже).

---

## Конфигурация

Файл `config.ini` содержит все настройки скрипта.

```ini
[auth]
login = ваш_логин
password = ваш_пароль

[settings]
resolution = 1920x1080
theme = nature
save_dir = C:\Users\USER\Pictures\GoodFon
max_files = 10
like_every_n = 10
max_attempts = 3
notify = true

[state]
counter = 0
```

### Описание параметров

| Параметр | Описание |
|---|---|
| `login` | Логин от аккаунта на goodfon.com |
| `password` | Пароль от аккаунта на goodfon.com |
| `resolution` | Разрешение скачиваемых обоев, например `1920x1080` или `2560x1440` |
| `theme` | Тема обоев — часть URL сайта, например `nature`, `cars`, `erotic` |
| `save_dir` | Папка для сохранения скачанных обоев (вписать своё имя пользователя)|
| `max_files` | Максимальное количество файлов в основной папке (старые удаляются) |
| `like_every_n` | Каждый N-й запуск берёт картинку из папки избранных. При `10` — каждый десятый |
| `max_attempts` | Количество попыток загрузки при ошибках сайта |
| `notify` | Уведомления в трей: `true` или `false` |
| `counter` | Счётчик запусков — управляется скриптом автоматически, не трогать |

### Как узнать название темы

Открыть нужный раздел на сайте, например:
```
https://www.goodfon.com/nature/
```
Название темы — это `nature`. Именно его нужно указать в параметре `theme`.

## Структура папок

После первого запуска скрипт создаёт следующую структуру:

```
📁 save_dir (например C:\Users\USER\Pictures\GoodFon\)
├── 📁 Like\
│   └── 📁 nature\        ← избранные картинки по теме
│       ├── wallpaper1.jpg
│       └── wallpaper2.jpg
├── wallpaper_current.jpg  ← последние скачанные обои
└── ...
```

Папка `Like\тема\` создаётся автоматически при первом добавлении в избранное. При смене темы в конфиге избранные из другой темы остаются нетронутыми.

## Запуск

Скрипт принимает один необязательный аргумент:

```
py GoodFon.py              # обновить обои (по умолчанию)
py GoodFon.py like         # добавить текущие обои в избранное
py GoodFon.py unlike       # удалить текущие обои из избранного
```

### Команда `like`
- Копирует текущие обои в папку `Like\тема\`
- Добавляет картинку в избранное на сайте
- Переключает обои на копию из папки `Like` (чтобы `unlike` работал корректно)

### Команда `unlike`
- Определяет текущие обои через реестр Windows
- Удаляет картинку из избранного на сайте
- Удаляет локальный файл из папки `Like\тема\`
- Сразу загружает новую картинку с сайта
- Работает только если текущие обои из папки `Like\тема\`

## Автозапуск через Планировщик задач

Чтобы обои менялись автоматически:

1. Открыть **Планировщик задач** (`taskschd.msc`)
2. Создать новую задачу → **Создать задачу**
3. Вкладка **Общие**: указать имя, выбрать «Выполнять для всех пользователей»
4. Вкладка **Триггеры**: добавить триггер → **По расписанию** → **Повторять каждые 10 минут** → **Бессрочно**
5. Вкладка **Действия**: добавить действие:
   - Программа: `C:\Users\USER\AppData\Local\Programs\Python\Python313\pythonw.exe`
   - Аргументы: `"C:\Users\USER\Pictures\GoodFon.py"`
6. Нажать **ОК**

> Используйте `pythonw.exe` вместо `python.exe` — он запускает скрипт без окна консоли.

## Контекстное меню рабочего стола

Для быстрого управления прямо с рабочего стола можно добавить три пункта в контекстное меню. Создать файл `goodfon.reg` со следующим содержимым, заменив пути на свои, и запустить его:

```reg
Windows Registry Editor Version 5.00

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFon]
@="Следующее изображение рабочего стола"
"Icon"="imageres.dll,-70"

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFon\command]
@="C:\\Users\\USER\\AppData\\Local\\Programs\\Python\\Python313\\pythonw.exe \"C:\\Users\\USER\\Pictures\\GoodFon.py\" update"

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFonLike]
@="Добавить в избранное изображение рабочего стола"
"Icon"="shell32.dll,43"

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFonLike\command]
@="C:\\Users\\USER\\AppData\\Local\\Programs\\Python\\Python313\\pythonw.exe \"C:\\Users\\USER\\Pictures\\GoodFon.py\" like"

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFonUnlike]
@="Убрать из избранного изображение рабочего стола"
"Icon"="shell32.dll,131"

[HKEY_CLASSES_ROOT\Directory\Background\shell\GoodFonUnlike\command]
@="C:\\Users\\USER\\AppData\\Local\\Programs\\Python\\Python313\\pythonw.exe \"C:\\Users\\USER\\Pictures\\GoodFon.py\" unlike"
```

После применения в контекстном меню рабочего стола появятся три пункта.

## Уведомления в трей

| Ситуация | Иконка | Сообщение |
|---|---|---|
| Обои загружены с сайта | 🖼️ | `С сайта: имя_файла.jpg` |
| Обои из папки избранных | ❤️ | `Из папки Like: имя_файла.jpg` |
| Обои из локальной папки (сбой сайта) | 📁 | `Локально: имя_файла.jpg` |
| Добавлено в избранное | ❤️ | `имя_файла.jpg` |
| Удалено из избранного | 🗑️ | `имя_файла.jpg` |
| Суточный лимит исчерпан | ⚠️ | `Загружаем из избранного` |
| Ошибка / нет картинок | 😞 | Описание ошибки |

Уведомления можно отключить в `config.ini`: `notify = false`

## Поведение при проблемах с сайтом

| Ситуация | Поведение скрипта |
|---|---|
| Сайт недоступен при старте | Меняет обои из `Like\тема\` без попытки логина |
| Ошибка пагинации (502, таймаут) | Повторяет попытку до `max_attempts` раз |
| Таймаут при скачивании картинки | Повторяет попытку с другой картинкой |
| Исчерпан суточный лимит загрузок | Переключается на `Like\тема\` |
| Нужное разрешение недоступно | Пропускает картинку, берёт следующую |
| Сервер `img.goodfon.com` недоступен | Автоматически пробует `img.goodfon.ru` |
| Все попытки провалились | Меняет обои из `Like\тема\` |
